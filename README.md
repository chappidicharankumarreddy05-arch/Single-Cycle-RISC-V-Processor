# Single-Cycle RISC-V Processor

## 🚀 [Click Here to View Live Demo](https://chappidicharankumarreddy05-arch.github.io/Single-Cycle-RISC-V-Processor/)

A **Single-Cycle RISC-V Processor Simulator** developed as a Computer Organization and Architecture (COA) mini project. This web application demonstrates the basic working of a processor by executing instructions and displaying register values, ALU operations, memory activities, and control signals.

## 📌 Project Overview

The Single-Cycle RISC-V Processor is an educational simulator designed to explain how a processor executes instructions in a single clock cycle. It provides an interactive interface to understand the processor datapath and instruction execution process.

## 🎯 Objectives

- Understand the architecture of a RISC-V processor.
- Demonstrate instruction fetch, decode, and execution.
- Understand arithmetic and logical operations.
- Visualize register and memory updates.
- Learn the functions of the ALU, control unit, and program counter.

## ✨ Features

- Interactive processor datapath visualization.
- Instruction-by-instruction execution.
- Register file displaying registers `x0` to `x31`.
- ALU arithmetic and logical operations.
- Data memory read and write operations.
- Control signal display.
- Program counter and cycle counter.
- Execution log for tracking instructions.

## 🛠️ Technologies Used

## ⚙️ How to Run

1. Open the live demo link at the top of this README.
2. Load or reset the sample program.
3. Click **Execute One Instruction** to execute one instruction at a time.
4. Click **Run Program** to execute the program continuously.
5. Observe the register values, memory, control signals, and execution log.

## 🧠 Working Principle

1. **Instruction Fetch:** The program counter identifies the current instruction.
2. **Instruction Decode:** The control unit identifies the instruction type.
3. **Register Read:** Source register values are obtained.
4. **ALU Operation:** Arithmetic, logical, or address calculations are performed.
5. **Memory Access:** Load and store instructions access data memory.
6. **Write Back:** Results are written to the destination register.
7. **PC Update:** The next instruction address is selected.
