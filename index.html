Project Objective & Working

  1. Fetch the instruction from instruction memory using the program counter.
  2. Decode the instruction and read source registers.
  3. The control unit selects the operation and the ALU calculates the result or address.
  4. For load/store instructions, access data memory.
  5. Write the result back to the destination register when required.
  6. Update the PC to the next instruction or a branch/jump target.

Note: This simulator models a teaching subset of RV32I with simplified assembly parsing. It is intended for COA demonstration and learning.
